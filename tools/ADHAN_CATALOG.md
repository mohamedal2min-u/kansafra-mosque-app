# قائمة الأذان الإضافي (تحميل عند الطلب)

الأذان المضمّن في التطبيق ثمانية مؤذنين. لإضافة المزيد دون زيادة حجم التطبيق، تُرفع الملفات على استضافة ثابتة ويضع التطبيق قائمتها في ملف JSON.

## 1. تحضير الملفات
لكل مؤذن ملفان mp3 أحاديان (32 kHz و40 kbps): نسخة كاملة وأخرى قصيرة نحو 17 ثانية، كما في `assets/adhan/`.

## 2. رفع الملفات
أنسب مكان: **GitHub Releases** في المستودع نفسه (مجاني). أنشئ Release باسم `adhan-catalog` وارفع الملفات، فيكون رابط كل ملف:
`https://github.com/mohamedal2min-u/kansafra-mosque-app/releases/download/adhan-catalog/<اسم الملف>`

## 3. ملف القائمة
ارفع ملفًا باسم `adhan_catalog.json` في Release نفسه بهذه الصيغة:

```json
{
  "voices": [
    {
      "id": "x1",
      "name": "اسم المؤذن",
      "credit": "المصدر - الرخصة",
      "long": "https://.../adhan_x1_long.mp3",
      "short": "https://.../adhan_x1_short.mp3"
    }
  ]
}
```
`id` أحرف إنجليزية وأرقام فقط ولا يتغير بعد النشر. يتجاهل التطبيق أي عنصر ينقصه `long` أو `short`.

## 4. التفعيل
ضع رابط `adhan_catalog.json` في `adhanCatalogUrl` داخل `lib/config.dart`. وهو فارغ الآن، فالميزة مخفية حتى يوضع الرابط.

## ملاحظات
- التحميل يتم مرة واحدة عند اختيار المؤذن (ومرة أخرى إذا بدّل المستخدم طول الأذان).
- يُحفظ الصوت في مخزن أصوات الهاتف (`Notifications/Kansafra`) ليشغّله النظام وقت الأذان. يعمل على أندرويد 10 فأعلى فقط.
- يبقى الأذان المضمّن بدون إنترنت. المؤذن الإضافي يحتاج إنترنت عند اختياره أول مرة فقط.

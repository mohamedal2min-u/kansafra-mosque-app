# تطبيق مسجد كنصفرة الكبير

تطبيق Flutter: مواقيت الصلاة وتنبيه الأذان، القرآن (قراءة بدون إنترنت + استماع)، التبرعات وقائمة المتبرعين.

## التشغيل
```
flutter pub get
flutter run            # هاتف أو محاكي أندرويد
flutter run -d chrome  # تجربة سريعة في المتصفح (بدون تنبيهات الأذان)
```
مجلد `android/` موجود وجاهز (الصلاحيات والإشعارات مضافة).

## الإعدادات في `lib/config.dart`
الإحداثيات، المنطقة الزمنية، تعديل دقائق كل صلاة، وبيانات التبرع.

## أصوات الأذان
مضمّنة في التطبيق (تسجيلات حرة CC0 / ملكية عامة، انظر `assets/adhan/CREDITS.md`):
المؤذن 2 (قصير، الافتراضي) والمؤذن 1 (كامل). يختار المستخدم من «الإعدادات» ويستمع قبل الاختيار.
لاستبدال صوت: ضع ملفًا بنفس الاسم في `android/app/src/main/res/raw/` (`adhan_short.mp3` / `adhan_full.mp3`) وفي `assets/adhan/`.

## القرآن
- **القراءة:** نص المصحف مضمّن في `assets/quran.json` (حوالي 1.3 ميغابايت)، يعمل بدون إنترنت ويُحمَّل عند فتح التبويب فقط، وتُبنى الآيات الظاهرة فقط على الشاشة.
- **الاستماع:** من واجهة mp3quran.net ويحتاج إنترنت. التصنيفات: الحرم المكي، الحرم المدني، مجوّد، مرتّل، تعليمي (تُستنتج من أسماء القرّاء والروايات).

## المتبرعون
الواجهة جاهزة (اسم أو «فاعل خير»)، لكنها تستخدم تخزينًا مؤقتًا في الذاكرة (`lib/donors/donors_repository.dart`).
لتظهر القائمة لكل المستخدمين يلزم قاعدة بيانات مشتركة (Firebase أو Supabase) ولوحة موافقة لإدارة المسجد.

نص القرآن مأخوذ من حزمة `quran` (MIT)، انظر `assets/LICENSE-quran.txt`.

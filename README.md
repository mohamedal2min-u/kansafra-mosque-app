# تطبيق مسجد كنصفرة الكبير 🕌

تطبيق جوّال لـ **مسجد كنصفرة الكبير**، مبني باستخدام **Flutter** ليعمل على أندرويد وiOS.

## هدف التطبيق

يهدف التطبيق إلى ربط أهل البلدة وروّاد المسجد بمسجدهم، وتسهيل متابعة شؤونه اليومية، من خلال:

- **مواقيت الصلاة:** عرض أوقات الصلوات الخمس وصلاة الجمعة بدقة حسب موقع المسجد.
- **الأذان:** تنبيهات وإشعارات بصوت الأذان عند دخول وقت كل صلاة.
- **التبرعات:** وسيلة سهلة وآمنة للتبرع لصالح المسجد ومشاريعه وأعمال الخير.

## التقنيات

- Flutter / Dart

## الحالة

المشروع في مرحلة البداية.

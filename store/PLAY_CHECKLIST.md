# قائمة جاهزية Google Play: مسجد كنصفرة الكبير

## قبل الإنتاج
- [ ] اختبار مغلق (Closed testing): 12 مختبرًا على الأقل لمدة 14 يومًا متواصلة (الحساب الشخصي الجديد).
- [ ] رابط سياسة الخصوصية: https://kansafra.alamin.se/privacy.html
- [ ] نموذج «سلامة البيانات» (Data safety): الإجابات أدناه.
- [ ] تصنيف المحتوى (Content rating) واستبيان الجمهور المستهدف.
- [ ] بصمة SHA-1 الخاصة بتوقيع Play (الإعداد ← توقيع التطبيق) تُضاف إلى معرّف OAuth لأندرويد في Google Cloud، ليعمل الدخول بجوجل في النسخة المنزّلة من المتجر.
- [ ] الأيقونة 512 والصورة المميزة 1024×500 ولقطات الشاشة (مجلد store/).

## إجابات نموذج سلامة البيانات
| السؤال | الإجابة |
|---|---|
| هل تجمع بيانات؟ | نعم (محدودة) |
| بيانات شخصية: معرّف المستخدم | نعم: معرّف جهاز عشوائي، والرقم المميز لحساب Google إن دخل المستخدم. الغرض: وظائف التطبيق (سجل التبرعات). غير مشاركة مع جهات خارجية |
| اسم / بريد / صورة | لا تُخزَّن عندنا. تُعرض على الهاتف فقط عند الدخول بجوجل |
| الموقع | لا (الموقع التقريبي اختياري، يُعالَج على الهاتف فقط ولا يُرسل) |
| المعاملات المالية | لا نعالجها داخل التطبيق |
| الإعلانات / التتبّع | لا |
| التشفير أثناء النقل | نعم (HTTPS) |
| طلب حذف البيانات | عبر صفحة «التواصل» (ماسنجر) |

## ملاحظات
- أذونات حساسة: الإشعارات، والتنبيهات الدقيقة (للأذان)، وخدمة مقدّمة لتشغيل القرآن في الخلفية. اشرحها في وصف المتجر.
- كتالوج الأذان الأونلاين: حقوق التسجيلات يجب أن تُوثَّق بإذن مكتوب قبل الإنتاج. مفتاح الإيقاف عن بُعد: ضع `"enabled": false` في `docs/adhan/catalog.json` فتتوقف القائمة دون تحديث التطبيق.
